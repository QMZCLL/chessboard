# 识别模型

把模型文件放在本目录，并在 `manifest.json` 中写明文件名与约定：

- `input_width` / `input_height`：模型输入尺寸（默认 640×640，RGB，按 255 归一化，NCHW）。
- `labels`：类别顺序，`0` 表示棋盘，其余为 FEN 棋子字母（默认 `nbakrcpRNAKBCP0`）。
- 输出：YOLOv5 格式 `[1, N, 4 + 1 + 类别数]`（中心点、宽高、objectness、各类别概率）。
- `confidence` / `iou`：置信度与非极大值抑制阈值。
- `sha256`：可选，给出后加载前校验。

预处理、标签与输出解析相互依赖，替换模型时请整体更新清单并用样例截图验证。
也可以在应用设置中指定其他位置的模型文件。
