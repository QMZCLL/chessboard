# 识别模型

把模型文件放在本目录，并在 `manifest.json` 中写明文件名与约定：

- `input_width` / `input_height`：模型输入尺寸（默认 640×640，RGB，按 255 归一化，NCHW）。
- `labels`：类别顺序，`0` 表示棋盘，其余为 FEN 棋子字母（默认 `nbakrcpRNAKBCP0`）。
- 输出：YOLOv5 格式 `[1, N, 4 + 1 + 类别数]`（中心点、宽高、objectness、各类别概率）。
- `confidence` / `iou`：置信度与非极大值抑制阈值。
- `sha256`：可选，给出后加载前校验。

除 `version` 与 `sha256` 外各项都必须写明。清单无法解析或不成立时识别不可用，不会改用默认设置
（标签顺序不对时不会报错，而是把一种棋子认成另一种）。本目录没有 `manifest.json` 时按自带模型的约定读取 `large.onnx`。

预处理、标签与输出解析相互依赖，替换模型时请整体更新清单并用样例截图验证。

也可以在应用设置中指定其他位置的模型文件，并在它旁边放一份同样格式的清单 `<文件名>.manifest.json`
（例如 `mine.onnx` 旁边的 `mine.manifest.json`），或在同一目录的 `manifest.json` 中把 `file` 写成它的文件名。
没有清单时，只有校验值与本目录清单中的 `sha256` 一致（同一个模型）才沿用本目录的清单。
修改设置后立即生效；加载失败后，替换模型文件或再次截图时会重新加载。
